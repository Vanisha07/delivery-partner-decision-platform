# Decision Intelligence Platform

A full-stack business analytics and decision-support platform.

## Stack
- Next.js + TypeScript
- FastAPI + SQLAlchemy
- PostgreSQL
- Pandas / scikit-learn (later phases)
- Docker Compose

## Start
```bash
docker compose up --build
```
- Frontend: http://localhost:3000
- API: http://localhost:8000/docs
- PostgreSQL: localhost:5432
